An offline, fully unlocked version of Marvel Snap called "Marvel Snap: Infinite

Features:
- Card Database: Features all 737 loaded cards and a studio to view variants, card backs, Icons and tokens in 3d.

- Deck Builder: Supports direct import/export with the base game. An integrated "Uatu the Watcher" advisor flags weaknesses, such as warning against top-heavy curves that brick opening hands.

- Meta Integration: Instantly equip tiered 12-card lists from a dedicated tab, including Tier 1 options like Death-Knull Destroy and Sera Control.

- Battle Arena: The AI's logic is built using Reddit's "How 2 Snap" guide and statistical data, training it to mathematically snap for extra cubes or retreat from perceived gin draws. The game features controller support & Netplay for private matches.

- Client Ecosystem: Mimics the live game with a News tab for OTA updates and season announcements, plus a settings menu for local profile customization. The game also automatically updates it's database on launch.
